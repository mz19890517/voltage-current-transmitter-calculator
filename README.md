# 电压/电流表变送输出计算器（Android）

辅助计算工具：4~20mA 变送输出的理论电压、偏差分析、单点/两点校准建议、实时监测（模拟）、参数保存与报告导出。

## 启动界面（v1.1.0）

- 带 Logo 的启动界面，标注「孟国胜制作」。
- 需要输入启动密码才能进入：密码为当前时间（24 小时制 时+分，如 17:37 → 1737）。

## 功能

- **理论计算**：输出电流 = 4 + 16 × (输入电压 − 下限)/(上限 − 下限) mA；输出电压 = 电流 × 采样电阻 / 1000。
- **偏差分析**：实测 vs 理论 — 绝对偏差 (V) 与相对偏差 (%)。
- **建议新上限**：以实测输出反推 / 以理论输出反推两组建议。
- **校准向导**：单点校准反推建议上限；两点校准给出零点零偏、实际量程跨度、增益系数、建议修正上限。
- **实时监测**：内置模拟数据源演示（默认 2% 增益误差场景），蓝牙/串口模块可接入替换。
- **设置与导出**：参数保存/加载到本地文件，计算报告导出为 .txt。

## 当前情况结论（内置示例）

输入 49.3V、上限 80、采样电阻 120Ω、实测 1.628V：
- 理论输出 1.663V，偏差约 −2.1%。
- 以理论输出反推上限仍为 80V；以实测输出反推 ≈ 82.5V（仅让该点与理论一致）。
- 偏差属硬件增益偏低，改上限无法完全消除，需硬件校准；接受 ±2% 误差可保持上限 80。

## 构建

GitHub Actions：推送到 `main` 自动构建，产物 `app-release.apk` 作为 artifact 上传。

本地构建：`./gradlew :app:assembleRelease`（需要 JDK 17 + Android SDK）。
